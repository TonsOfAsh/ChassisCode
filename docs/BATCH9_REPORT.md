# Batch 9 report

Researched 4 October 2026: 25 cars. 23 added (17 normal, 6 provisional), 2 held. The database is
at 221 cars (43 provisional, Unlimited only); 11 cars are held. Every record was re-checked by an
independent agent; no power or weight figure was invented.

Corrections after the check: the Trans Am's weight was the Formula's (3,453 lb), now the Trans Am
page's 3,479 lb; the Mustang GT's 412 hp is a Ford estimate, so power is provisional too; the 488
Pista's 1,385 kg kerb figure came only from Evo's article text and a sister title, so the record
uses Ferrari's dry weight (step 4); misquotes fixed (NSX Type S, Panamera, GTO) and an off-topic
citation removed (M4 CSL); the Artura's 690 hp now cites The Drive's report that it began with
model year 2025.
